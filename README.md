# AWS SBG Tasks

Weekly Python tasks for the AWS SBG program. Each week has its own folder
with the source code, a Google Colab notebook, and a short README
explaining the task.

## Repository Structure

```
aws-sbg-tasks/
├── README.md
├── week-01/
│   ├── README.md
│   ├── student_scores.py
│   ├── student_scores.ipynb
│   └── data/students.csv
├── week-02/
└── ...
```

## Weekly Tasks

| Week                 | Task                          | Topics                       |
| -------------------- | ----------------------------- | ---------------------------- |
| [Week 01](./week-01) | Student Score Data Processing | Pandas, NumPy, data cleaning |

## Submission Format

Every week includes:

- a `.py` file with the Python source code
- a `.ipynb` Google Colab notebook with code, outputs and short explanations
- a `README.md` describing the task and how to run it

## How to Run

```bash
git clone <your-repo-link>
cd aws-sbg-tasks/week-01
pip install pandas numpy
python student_scores.py
```
